CAD-Acid

An acid test for CAD kernels.

Part of the wonky project — a Rust CAD kernel that speaks Onshape's FeatureScript and build123d, aims to be exact and introspective, refuses rather than guesses, and checks its work against Onshape.

Status report

Rust tested code tree SHA-256: 9293eb2ac24c9e81a9a864e3ef1d9eefb4c269d0d4a1cff84d4f0b9fad7efeec. Git HEAD (which can omit uncommitted changes): not recorded. Onshape and build123d / OCCT are frozen independent references, not live runs today. Scores use 48 zones per kernel; disputed zones stay in the denominator. The strict score follows the frozen v1 rules (including declared measurement tolerances). The practical score additionally accepts only rule-cited, documented tolerance behaviour; it never accepts a changed solid as correct.
