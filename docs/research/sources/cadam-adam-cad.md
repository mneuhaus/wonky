## What it is

DOCUMENTED: a React/TypeScript authoring app where an LLM emits OpenSCAD, a WASM OpenSCAD compiler executes geometry in the browser, Three.js displays it, and source-derived parameters expose sliders/switches/text/color controls. Supports BOSL, BOSL2 and MCAD; parametric exports include STL, SCAD and projected DXF. Current source also has a separate creative mesh-generation path; that is not editable analytic B-rep CAD. [README](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/README.md), [tool schemas](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/shared/chatAi.ts).

DOCUMENTED correction to the browser-only marketing phrase: **compilation is local, the whole service is not local/offline**. TanStack server routes call model providers; Supabase stores/authenticates conversations and uploaded inspection renders. The server downloads rendered images and attaches them to the next model request. Self-hosting still needs provider credentials unless independently replacing inference. [Architecture/config](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/README.md), [server tool-output conversion](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/src/server/aiChat.ts#L986-L1040), [client uploads](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/src/components/chat/ChatSession.tsx#L455-L526).

## How it works

### Artifact and verification protocol

DOCUMENTED current version is more than one-shot text-to-SCAD. Zod artifact schema is {title, version, code}; code must have at least 20 characters but semantic validity is checked by compilation. build_parametric_model is client-executed; tool result includes success message plus inspection view list/imageAttached. answer_user is a separate final-text tool. The server forces the build tool on first parametric step where provider capabilities permit, otherwise falls back to prompting and logs missed builds. It configures stepCountIs(60) for the parametric stream; client continuation also governs multi-request flow, so this should not be described as a guaranteed global 60-compile cost cap. [shared/chatAi.ts](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/shared/chatAi.ts), [server first-step/stop policy](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/src/server/aiChat.ts#L1310-L1378).

DOCUMENTED loop: complete source → browser compile → STL and optional colored OFF → seven-view sheet (ISO, front, back, left, right, top, bottom) → upload → compiler diagnostics or sheet returned to model → rewrite if necessary. System prompt explicitly distinguishes successful compilation from satisfying the user's geometry. Missing preview upload degrades to code-only review and does not fail the build. Thus visual review is requested, not mechanically guaranteed. [Prompt](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/src/server/aiChat.ts#L173-L218), [ChatSession tool handler](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/src/components/chat/ChatSession.tsx#L444-L573).

DOCUMENTED persistence ordering: upload inspection image and persist terminal tool state **before** triggering auto-continuation; if DB persistence fails, pause to avoid continuing against stale source. A load-time recovery function converts abandoned input-streaming/input-available tool calls to output-error but does not rewrite a live stream. These are concrete operational patterns for crash-safe agentic CAD, independent of the geometry backend. [ChatSession](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/src/components/chat/ChatSession.tsx#L530-L566), [stuckToolRecovery.ts](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/src/components/chat/stuckToolRecovery.ts).

### Deterministic parameter edits

DOCUMENTED shared/parseParameters.ts derives controls from source, not model-supplied parallel metadata. It scans declarations above the first unindented module/function, recognizes scalar decimal literals, booleans, strings and simple arrays, and interprets OpenSCAD Customizer comments:

- min:max or min:step:max ranges; enum options with optional labels; a bare numeric comment gives numeric step or string max length.
- A preceding comment is description; section markers define groups; snake_case names become labels.
- Numeric arrays are flattened to names such as size[0], with human axis/dimension labels.
- Computed expressions, nested arrays, many multiline forms and scientific notation are outside this regex parser's supported literal grammar.

[Parser and explicit AST TODO](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/shared/parseParameters.ts).

DOCUMENTED edit path: 200ms debounce, patch assignments into the full source through updateParameter, update preview and recompile **without an AI request**. Queue DB writes serially and coalesce latest pending snapshot per message to prevent stale writes winning. originalCode metadata pins the initial defaults for Reset/range calculation without duplicating original source in model context. Unmount flushes pending debounce edits. This is much more concrete than 'sliders extracted automatically'. [ParameterSection](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/src/components/parameter/ParameterSection.tsx#L78-L135), [EditorView](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/src/views/EditorView.tsx#L478-L584), [patcher](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/src/lib/utils.ts#L107-L151).

### Worker and geometry execution

DOCUMENTED wrapper creates a **fresh WASM instance per compile** because reusing one previously produced opaque numeric exceptions. It copies workspace files/font to a virtual filesystem, detects actual include/use statements after lexically stripping comments/strings, fetches/unzips only referenced libraries, writes input.scad and calls OpenSCAD CLI. Library-fetch failure is fatal rather than continuing with 'unknown module' warnings and missing geometry. [openSCAD.ts#getInstance/executeOpenscad](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/src/worker/openSCAD.ts).

DOCUMENTED preview explicitly selects --backend=manifold and emits STL plus OFF. OFF carries per-face RGBA for color display; no global binary-STL format override because it would corrupt the companion OFF. Single-file export uses binary STL. 2D top-level geometry retries as SVG. Errors serialize source plus stderr across the worker boundary so the model can act on compiler messages instead of an opaque WASM throw. [Preview/export](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/src/worker/openSCAD.ts#L161-L277), [worker error serialization](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/src/worker/worker.ts).

DOCUMENTED worker lifecycles: per-viewer workers isolate preview state and stop on real unmount; a module-singleton tool worker outlives conversation navigation, routing responses by request ID. Source comments describe the prior shared-viewer bug (thumbnail STL contaminating main viewer and allocation errors) and unmount-killed tool builds. The tool worker does not implement a compile deadline in the inspected file; moving work off the UI thread alone does not bound resource use. [useOpenSCAD](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/src/hooks/useOpenSCAD.ts), [toolWorker.ts](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/src/worker/toolWorker.ts).

## Robustness and guarantees

DOCUMENTED: compile result is success when OpenSCAD exits successfully and output bytes are read. No topology identity, exact dimension verification, minimum wall certificate, parameter-domain proof or interference checker appears in this tool contract. Printability/manifoldness are partly instructions to the model, not a measured safety certificate. Multi-view screenshots cannot expose all cavities or sub-resolution tolerances. [Tool output schema](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/shared/chatAi.ts), [executeOpenscad return path](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/src/worker/openSCAD.ts#L447-L495).

DOCUMENTED/INFERRED static source mismatch worth not copying: parser converts size=[10,20,30] to scalar Parameter records named size[0], size[1], size[2], but EditorView feeds each directly into updateParameter, whose assignment regex searches for a literal size[0]= declaration. The original source only contains size=[…], so those scalar controls cannot patch that declaration through this call path. No array-element reassembly occurs in the inspected changeParameters loop. This is a static finding, not a locally executed reproduction. It illustrates why stable AST/source binding matters more than regex-only parameter discovery. [Parser array flattening](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/shared/parseParameters.ts#L169-L190), [actual edit loop](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/src/views/EditorView.tsx#L555-L563), [patcher](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/src/lib/utils.ts#L107-L151).

DOCUMENTED range/units are UX heuristics: missing numeric ranges derive from magnitude-rounded defaults; step approximately 1% of range; measurement label inferred from names like width/radius/gap. validateParameterValue only rejects NaN and otherwise returns a number; it does not establish joint validity of dependent parameters. INFERRED: sliders can drive walls negative or features beyond kernel-supported ranges unless source or kernel checks them. [parameterUtils.ts](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/src/utils/parameterUtils.ts).

## Parallelism and performance

DOCUMENTED: browser Web Workers preserve UI responsiveness, with request-ID routing and zero-copy transfer for uploaded ArrayBuffers. They are not a demonstrated parallel geometry algorithm or uniform GPU execution system. Current WASM binary is about 9.2 MiB. The JS glue exposes Float64Array/HEAPF64 as well as Float32Array; this is not an F32-only substrate, and JavaScript parameter arithmetic uses Number. Native OpenSCAD/Manifold numeric internals were not audited here. [Worker implementation](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/src/worker/openSCAD.ts), [WASM glue](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/src/vendor/openscad-wasm/openscad.js), [zero-copy input](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/src/hooks/useOpenSCAD.ts#L119-L150).

DOCUMENTED no rigorous timing distribution/success-rate benchmark found. README's 'in seconds' and 'instant' are product claims. benchmarks/ has 13 selected prompt/source/GIF showcases, not randomized tasks with denominators, hidden failures or common compute budgets. The M12 bolt/nut source really calls BOSL2 screw(spec=...) and nut(spec=...) with $fn=64, demonstrating high-level library leverage, not an independently validated printed fit. $fn controls facet resolution, not certified maximum surface deviation. [Showcases](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/benchmarks/README.md), [thread example](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/benchmarks/03-hex-bolt-and-nut.scad).

## Relevance for wonky

INFERRED highest-value transfer is **separate stochastic authoring from deterministic edits**. Wonky already interprets unmodified FeatureScript, so use its AST, typed units and source spans to expose parameter identity, default, range, dependencies and semantic descriptions. Do not adopt regex extraction or a second LLM-generated metadata structure that can disagree with code. A slider should produce a parameter patch against a particular program version, execute in Bend, and return geometry/provenance diff without spending another model generation. Preserve immutable original defaults and batch rapid edits while discarding stale render results. [Motivation: parser and edit architecture](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/shared/parseParameters.ts), [EditorView persistence](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/src/views/EditorView.tsx#L478-L584).

INFERRED verification protocol: retain compile → seven-view inspect → revise, but add machine-readable dimensional checks, raw solid validity, certified mesh deviation, operation provenance, unsupported-feature diagnostics, interference and FDM walls/clearances. Persist artifact+checks atomically before continuation; count missing render as unavailable inspection, not proof it looks right. Bound total steps, token cost, compile time and geometry memory explicitly across client restarts. These are proposed wonky improvements, not established CADAM guarantees. [Agent result/persistence evidence](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/src/components/chat/ChatSession.tsx#L444-L573).

INFERRED Bend fit: UI/job/state protocols are frontend concerns, so their JS mutation does not need a Bend port. Geometry jobs should call the Bend interpreter/kernel only, using immutable request/result values and stable IDs. Balanced fork-join may parallelize independent validation/render preparation; asynchronous Web Worker concurrency says nothing about Bend's uniform Metal call trees. Parse dimensioned values explicitly to F32x2 with range checks; never silently inherit JavaScript/f64 numerical assumptions. OpenSCAD WASM/Manifold are prohibited as production geometry backends under wonky's no-FFI rule. High-level FeatureScript library operations can provide BOSL2-like authoring leverage but need native Bend implementations and separate license review. [Runtime/source basis](https://github.com/Adam-CAD/CADAM/blob/eb216809c04fc353a58c3806e01e8b6676ee8488/src/worker/openSCAD.ts).

## Verdict: adapt

Independently adapt deterministic parameter editing, provider-independent artifact schema, persistent execution state, rich compiler errors and multiview verification UX. Do not copy the GPL code or embed its WASM kernel by default. CADAM provides convincing product patterns and visible demand, not evidence of exact B-rep/FDM correctness. Open: array-parameter round trips, bounded tool execution, quantitative success/latency data and an actual geometry-to-source feature tree.
